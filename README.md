# رابط | RabetMediaBot

بوت Telegram عربي مستقل يستقبل الروابط العامة من X/Twitter وTikTok وInstagram وYouTube، ثم يرسل الفيديو للمستخدم بعد تنزيله ومعالجته.

- اسم البوت: **رابط**
- اسم المستخدم: **@RabetMediaBot**
- العبارة: **أرسل الرابط… واستلم المقطع.**

## الحدود المقصودة

- المحتوى العام الذي يملكه المستخدم أو لديه إذن بتنزيله فقط.
- لا يدعم المحتوى الخاص أو المدفوع أو المحمي بـ DRM.
- لا يستخدم Cookies أو حسابات المنصات.
- لا يدعم البث المباشر أو قوائم التشغيل.
- YouTube يُستخدم فقط عندما تسمح الخدمة بالتنزيل أو يملك المستخدم تصريحًا مناسبًا.
- الملفات المؤقتة تُحذف فور اكتمال الطلب.

## المزايا الحالية

- واجهة Telegram Mini App عربية حديثة ومتجاوبة مبنية بـ HTML/CSS.
- شعارات واضحة للمنصات وشريط تنقل للتحميل والمساعدة والخصوصية والحقوق.
- زر دائم أسفل المحادثة لفتح الواجهة وإرسال الرابط إلى البوت مباشرة.
- صفحة حقوق مستقلة باسم المصمم والمطوّر ووسيلة التواصل الرسمية للمشروع.
- كشف المنصة والتحقق الصارم من النطاق.
- تنزيل بجودات متدرجة من 1080p إلى 360p للوصول إلى حد Telegram.
- دمج الصوت والفيديو عبر FFmpeg.
- حد استخدام لكل مستخدم ومنع الطلبات المتزامنة من الحساب نفسه.
- تنظيف تلقائي للملفات وعدم تخزين بيانات المستخدمين في قاعدة دائمة.
- إعداد Docker وRailway جاهز.

## التشغيل محليًا

1. أنشئ بوتًا جديدًا من `@BotFather` وانسخ الرمز.
2. انسخ `.env.example` إلى `.env` وضع الرمز في `TELEGRAM_BOT_TOKEN`.
3. ثبّت Python 3.12 وFFmpeg.
4. نفّذ:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
set -a && source .env && set +a
python -m app.main
```

## الاختبارات

```bash
python -m unittest discover -s tests -v
```

## النشر على Railway

1. ارفع المشروع إلى مستودع GitHub جديد.
2. أنشئ مشروع Railway من المستودع.
3. أضف المتغير `TELEGRAM_BOT_TOKEN` في Variables.
4. أضف `WEB_APP_URL` بقيمة رابط Railway العام متبوعًا بـ `/app`.
5. اترك Railway يبني `Dockerfile` ويشغّل الخدمة.

لا تضع رمز Telegram داخل GitHub أو داخل أي ملف يتم رفعه.
